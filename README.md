# ✨ Overview

**1Street** is a full-stack e-commerce platform created to demonstrate modern web development principles and online shopping workflows. The project includes product browsing, user authentication, shopping cart management, and responsive layouts designed to provide a seamless experience across desktop and mobile devices.

The architecture emphasizes maintainability, scalability, and performance while keeping the codebase simple enough for learning and future expansion.

